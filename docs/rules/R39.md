# R39

## Rule

**R39.** Web lookup (2026-11-12): `search_web` and `read_page` are reads, open-world (an agent’s 6 a minute at the
door). A query leaves with its key shapes hidden (`maskSecrets`) and the fleet’s own details too (`hideFleet`:
`*.ts.net` names, the hosts of `config.json`’s `origin` and `nodes`, any address that isn’t public, the name in a
`/home/<name>` or `/Users/<name>` path), then is cut to 200 characters; it goes to DuckDuckGo’s page without
JavaScript or the owner’s SearXNG (`config.json` `webSearch.searxng`, the owner’s own address); a refusal or a robot
check is never answered or tried again: it says web search didn’t answer just now. `read_page` opens an address only
when it is in the owner’s own words in this chat (`ctx.ownerWords`: every message of theirs in it, never an agent’s, a
notice or a carry-on line; one typed without `https://`, like `docs.vllm.ai/en/latest`, counts as `https://`: a name
with a dot and a top-level domain of letters) or `search_web` returned it in the last hour (`webSeen`, in memory),
compared whole without its `#fragment`; an agent (directly or through `ask_sparkie`), `POST /actions` and a workflow
step get only the second. Only http(s), no name or password in the address, no cookies or credentials, 3 redirects at
most, 15 s and 2 MB; a `Content-Encoding` it can’t unpack (`constructor` and `__proto__` too) fails that read, and
nothing a response throws can end the process. Every hop is refused before it connects unless all its addresses are
public: none in loopback, private, CGNAT (`100.64.0.0/10`, the tailnet), link-local (cloud metadata too), the IETF and
documentation blocks, multicast or reserved, and IPv6 only in global unicast (not `::1`, unique-local, link-local or
IPv4-mapped). Names are checked by the lookup the connection itself uses (`publicLookup`), numbers and `localhost`
before it, so a redirect or a DNS answer that changes can’t get around it. The text is labelled as data
(`textIsData`), 12,000 characters at a time with `more` and `next`, and counts as outside text (`readOutside`); a page
never causes a change, because the change gate (R25) reads only the owner’s words. Parsing a page is linear in its
size. Sparkie’s prompt says its training may be out of date, so it looks up anything new or version-specific first and
says where the answer came from.

## Why

A page could make Sparkie put fleet data into an address, or reach the fleet, the tailnet or cloud metadata from
Spark 2.
