# R63

## Rule

**R63.** What bounds a plain change. The sorter will never be provably complete, so the run wall (R42) bounds what a
command it wrongly lets through can cost: never the Spark, the fleet, a model or the owner's way in. Each setting is
the root helper's own text, each has its try in the proof (attempts 11 and 21 to 26), and `--open` (an asked change
with the owner's groups) drops the network, device and home bounds.

- **The lists** (both walls): hidden, in every home, `.ssh` (its `authorized_keys`, `known_hosts`, `config` and
  `*.pub` put back read-only, plain files only), Spark Console's state folder (its plain files put back but the
  sign-in files, the sockets and the owner's words), the start files (`.profile`, `.bashrc`, the other bash and zsh
  ones, `.pam_environment`), the service manager's folders (`.config/systemd`, `environment.d`, `autostart`,
  `user-tmpfiles.d`, `.local/share/systemd`), the tools' key folders (`.kaggle`, `.config/rclone`, `.config/gcloud`,
  `.ollama`, `.claude`, `.claude.json`, `.codex`, `.gemini`, `.config/github-copilot`, `.config/anthropic`, `.openai`,
  `.azure`, `.wandb`, `.vault-token`, `.terraform.d`, `.gnupg`, `.aws`, `.kube`, `.ngc`, `.config/gh`, `.docker`, the
  Hugging Face tokens, `.netrc`, `.git-credentials`, `.npmrc`, `.pypirc`, `.pgpass`, pip's settings), the console's
  own secrets and journal, and histories; with `/run`, `/root`, the shadow files, the host keys, `/etc/ssl/private`,
  the network settings, Tailscale's, Docker's and containerd's data, `/var/lib/spark-console`, `/var/backups` and swap
  files. Read-only in a change: Spark Console's caches, set-up scripts, page, code and source, the editor's programs,
  the helper and its line (with `--open`, the start files and the service manager's folders instead).
- **The top of the home is read-only** in a plain change: nothing made, removed or renamed directly in `~`; every
  dot name there read-only but the download caches `.cache`, `.npm`, `.cargo/registry` and `.cargo/git`; `~/bin`
  read-only; the other plain folders there writable, each the real folder and on no list. Only inside those writable
  folders are the folders above a held path pinned (R42); the shared folder and the jobs' folders are read-only with
  the rest of `.local`.
- **The network**: no port off the loopback but the resolver (127.0.0.53), and none in the private, link-local,
  unique-local or tailnet ranges; `--fleet` lifts those ranges (never the loopback), for a change that was asked.
- **No devices** (`PrivateDevices`); `--gpu` keeps them, for a change that was asked. Its own `/dev/shm` and IPC.
- **Memory, processors, disk**: its cap (`--memory`, 1G to 8G; 8G without), no swap, a weight of 20 for the
  processors and the disk's traffic; it does not start while the home's disk has less than 50 GB free, and is ended,
  saying so, when the free space falls under that while it runs.
- **The home itself**: its mode and owner are noted before a change and put back right after it, as root, and any
  added access rules taken away; the answer says so (`chmod 777 ~` would make sshd refuse the owner's key).
- **`--protect`**: up to eight folders, a whole path or `~/` and a folder in the owner's home (from `/etc/passwd`),
  each there and real, no link at any part. **Groups**: `adm` and `systemd-journal` are left out with the docker, lxd,
  libvirt, disk and sudo groups.

## Why

The wall analyst's "what a sorter miss can cost" (2026-11-15): without these a wrongly sorted plain change could lock
the owner out (`chmod 777 ~`), read a token from a start file or a tool's folder, reach the home network, the other
Sparks and their models, use the GPU, leave a program the owner's next terminal runs, fill the disk, or keep files and
memory in `/dev/shm`. What is left: a project's own files on that one Spark, read or changed for the change's time.

## Today

Built in the helper; the console's half (`--protect` for the model store, the Hugging Face cache and the shared folder
on every plain change; a plain change starting in a work folder; no "at once" while a Spark has Tailscale SSH on) is
A7c's. `SocketBindDeny=any` is not set: it would stop a change's server or dev server and any client that binds
first, and needs systemd 249 (the helper asks 248). The disk floor and the home's put-back are the helper's own acts,
not wall settings: the tests show them on the stand-ins, not the proof.
