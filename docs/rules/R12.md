# R12

## Rule

**R12.** Approval arguments (`allowStop`, `allowBusy`, `confirmOutside`, `confirmRouted`, `__validate`) stay out of
public schemas; only server code sets `ctx.trusted`; a choice works once, for its asker, for 15 minutes. The Yes of a
stop question carries the start it was asked about: `spark` for one Spark, `sparks` for a pair, also when Spark
Console picked the pair (F11). A change of Sparkie's that `runAction`'s gate asks about says which gate asked, in
code's own short words on the question it hands back (`askedBecause`, for the eval's record): `words` (the owner's
words don't ask for it clearly), `rail` (the brain isn't checked, R52), `page` (from a channel it waits for the page).
An action's own questions (which model, a stop outside Spark Console, a model in use, a new image) and the box's
(`boxGate`, `21-box.mjs`; `21-box-fill.mjs`) carry none: their reason isn't handed to `propose` there, and their words
say it.

## Why

Callers must not answer their own questions.
