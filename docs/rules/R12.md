# R12

## Rule

**R12.** Approval arguments (`allowStop`, `allowBusy`, `confirmOutside`, `confirmRouted`, `__validate`) stay out of
public schemas; only server code sets `ctx.trusted`; a choice works once, for its asker, for 15 minutes. The Yes of a
stop question carries the start it was asked about: `spark` for one Spark, `sparks` for a pair, also when Spark
Console picked the pair (F11).

## Why

Callers must not answer their own questions.
