# R2

## Rule

**R2.** 8 GB stays free on every Spark; unreadable memory refuses the start. Today: holds for model starts, restarts,
the agent rails and every change inside the lock-out net (root's 8 GB cap, Spark 2's 2 GB: `netGuarded`, R71); the brain’s own start and switch measure nothing, the brain keeper’s start included. The figure
lives in `KEEP_FREE`, `HEADROOM` and literals in `pickVersion`. One GPU thing per Spark (A13, the owner’s decision of
2026-11-12): a GPU app or job (`keep_running` with `gpu`, labelled `spark.gpu=1`) starts only where no model, model
server or other GPU app runs (`gpuAlone`, also on a bring-back), and a model start counts it as a stop that is always
asked about, even while `nvidia-smi` lists nothing for it (`gpuUsersScript`’s fourth column, `plan`’s `hold`, `fitOf`,
`railsFor`); `restart_model` there is refused (`restartChecked`). A model and a GPU app never share a Spark’s memory.
A restart and a stopped GPU app's start look at room and the GPU again inside their claim, just before `docker start`
(`restartRoom`, `restartJob`; `keep_running`): what came between the first look and the claim stops them, and they
start nothing.

Running out freezes the machine.
