# R28

## Rule

**R28.** Edit parts, never `server.mjs`; rebuild. A part’s name matches `^\d{2}-[a-z0-9-]+\.mjs$` (a capital or
underscore is silently left out of the build; the installer compares against a shell glob, so a name that sorts
differently makes it refuse); imports only in part 01; top-level code uses earlier parts only; no npm packages.

## Why

Parts are concatenated as written.
