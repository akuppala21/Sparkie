# R74

## Rule

**R74.** Which of the owner's own words ask for a change (`changeIntent`, R25's first half; C-1, C-6, S-3, A-18).

- **Their own sentences only** (`ownSentences`, C-1): code blocks (fenced or indented), `>` lines, quotes or backticks
  of more than three words (a name or path stays: rename "old.txt" to "new.txt"), lines that read as a log, a diff or a
  program's output (and the plain lines between two), and the lines after one ending in ":" up to a blank line are no
  ask.
- **A call-off wins** (`calledOff`, C-6): a later sentence that only calls off ("Actually don't.", "Never mind.",
  "Wait.", "Cancel that.", "Not yet.") rules out every kind asked before it in the message; one that ends in a call-off
  after a comma or a dash rules out its own. For every kind the reader knows.
- **Where an order puts its verb** (`orderAt`, A-18, S-3): a change word of any kind (start, stop, restart, keep,
  power, work, file, memory and the rest) asks for a change only as the first word the owner says to Sparkie in that
  sentence, after nothing but a short closed list of openers: a greeting or a joining word (ok, so, and, now, then,
  also, just, yes, thanks, please, hey, Sparkie …), a place or a manner ("on Spark 3,", "Spark 3:", "as root on
  Spark 3,"), or a request to Sparkie ("can you", "could you", "I want you to", "I need you to", "go ahead and",
  "let's"). A later part after a comma, "and" or "then" counts only when the sentence itself began as an order ("pull the repo on Spark 3 and build it"). Never as a
  noun ("Update: …", "Try as I might", and for a work word "the build is slow", "build 42"). An order has no subject of
  its own, so a habit, someone else's words, a plan, a wish or a description ("I used to free up Spark 4 every night.",
  "My colleague says to fix the loader on Spark 3.") asks for nothing.
- **The trade:** a statement and an order in one sentence ("The loader on Spark 3 is broken, fix it.") is a button;
  said as two sentences, it runs at once. "You can install it on Spark 3 now" is asked too.
- `orderAt(sentence, match, kind)` is the one function for the order's place; `netAsks` (21-net.mjs) can call it as
  `orderAt(sentence, at)`, with its own verb's index.

## Why

A sentence about a change is not an order to make it. A word missing from the openers costs a button, not a change.
