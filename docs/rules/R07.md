# R7

## Rule

**R7.** Session tokens and agent keys are stored as hashes; results to agents and Sparkie’s tool results pass
`maskDeep`, chat notices pass `maskSecrets`. The owner’s words and Sparkie’s answer are masked when saved
(`sparkieTurn`: the message, the chat title, the carry-on request, the answer), so `chats.json` and its daily copy
hold no key; this turn’s gate and the model still get the words as typed, and the live stream is not masked. The mask
also hides the value after a name ending in `_key`, `-key`, `_pass` or `-pass`, after `passphrase` and after `PGPASS`
(F20). An app’s or job’s `command` (A13) is refused when a word would be masked or a secret-named flag is followed by
anything but a word that says there is none (`commandWords`: code-server’s `--auth none` passes), and its button shows
the words masked one by one. Fault and crash text passes `maskSecrets` before it is kept (`recordFault`,
`recordCrash`); the `where` of a route is its pattern, never an id or query. Telegram bot tokens are one of the masked
patterns, and `tell()` also replaces the bot’s own token wherever it appears (R32). `files` masks a file’s text in the
action itself (`hideKeys`: key shapes only, never plain words), so the owner’s `POST /actions` is masked too. `audit`
masks the asker’s words and the error the same way as the arguments, and the words are masked before they are cut.
`maskSecrets` is `hideKeys` plus a secret-named flag’s value (quoted too) and a labelled value; a flag must start a
word and Basic must follow “authorization”, so plain words pass. The command `running_models {detail}` returns is
masked where it is read (`learnedFrom`), so `POST /actions` is covered too; it never returns an environment name or
value. Today: the fleet notes sent to the brain are not masked and quote operation errors; `worker.py`’s own log rule
(`redact_logs`) is narrower and was left alone on purpose (editing it changes every workflow version); a no-password
flag typed in a chat (`--auth none`) is saved as `--auth [hidden]`.

## Why

Logs and commands hold keys.
