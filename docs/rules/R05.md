# R5

## Rule

**R5.** Transport and sender are judged before identity: Funnel never gets a Tailscale identity; a Spark’s own address
reaches only `/v1/` and starts nothing. Spark Console has one address, the main one (`config.json`’s `origin`, on the
tailnet or through Funnel); there is no second address or copy of the page to judge. The app door (R40) on port 10000
of the same name serves kept apps only, never the API or the page, and refuses the Sparks’ addresses the same way.

## Why

The Sparks are signed in as the owner.
