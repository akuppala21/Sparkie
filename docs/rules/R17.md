# R17

## Rule

**R17.** Console containers are `sc-<model>` with labels `spark.console=1` and `spark.model`; a pair’s second part is
`sc-<model>-part2` and both parts add `spark.cluster` and `spark.rank`; a pair needs a `full` cable test. The brain’s
container carries `spark.console=1` too, with `spark.role=main` and `spark.protect=true`.
A model from a Hugging Face cache sees its copy’s own folder, read-only (`hfMounts`). A snapshot file that links out of
that folder is mounted by itself only when it is a weight file (`.safetensors`, `.gguf`, `.bin`, `.pt`, `.pth`) that
leads to a plain file; any other link out, a copy whose folder is itself a link, or a name or link with a comma, quote
or line break stops the start before `docker run`, with one line naming the file. A cache reached through a link above
the copy’s folder (on another disk) is judged where that folder really is. A link inside the folder must lead to a
plain file too. A copy to another Spark (`copyModel`, which follows links and hands the bytes over) checks the same
rule (`hfEachFile`, one definition for both) on the snapshot and `refs/` before anything is sent, and there a weight
file that leads out must also be at least 16 MiB; otherwise the copy stops with one line naming the file. The receiving
Spark only unpacks into its staging folder (A-21); when both ends ended 0 (a process ended by a signal, as a cancel's,
is not 0), a second command moves it into place, and the copy counts only if that ended 0 too. Otherwise the staging
folder is removed and that is looked at: a removal that failed is said, with the command to run there. When only the
move failed (both ends 0; often files a container left as root at the final place), the words name the receiving Spark,
never the sender, and the whole copy is kept in staging there (never shown as a model) with the one command that
finishes it (W-9). The next start still copies again: the staging folder is cleared before each copy, since a copy kept
there could be older than the sending Spark's folder by then, and nothing checks it against that.

## Why

Everything finds deployments by these. Docker mounts as root, so a link put in a model’s folder must not bring any
other file of the Spark (a key, a socket, the home) into its container, nor onto another Spark as an ordinary file.
