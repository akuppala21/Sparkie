# R27

## Rule

**R27.** Setup commands are read by code, vetted by `dig.vetSetup`, and checked again by `resolveHow` at use. Today
that covers Recipes setups and verified runs; a model’s own `spark.json` is checked only on the Sparkie and agent path
(`agentSafeSetup`): page Deploy with no setup named runs it as written, and the brain switch puts its args and image
into the brain’s docker run. A model’s own card on Hugging Face is a source (`cardText`, `cardSetups`, `dig.fromCard`,
A9): only commands in its fenced code blocks (read in one pass over its lines, never its HTML: a hostile card takes
milliseconds) that serve that very repo, kind `model-card`, read last, no speed, never a base model’s card.

## Why

One click runs them as written.
