# R1

## Rule

**R1.** No new workload starts on the hub (the brain’s Spark and the console’s own), named or not. A named Spark is
checked by `notBrainsSpark` against both (`brainSparks()`). Placement that names no Spark picks only among
`computeSparks()` (every Spark on the list but the hub): `placeModel`’s single Spark and its pairs, and `pickVersion`’s
download target. The self-test picks from `computeSparks()` too, and each of its steps checks again. Today: the brain
switch can start any library model there as the brain. `keep_running` refuses the brain’s Spark for every verb (R38).
A command `run` would change on Spark 2 (A11, `21-hub.mjs`; `HUB_ON`, on; a stand-in fleet's off side does not do it) is
refused by code before anything is asked, each in its own words: anything that stops, restarts, removes or changes the
brain’s container or its model files (a container program other than a start, a name of the brain’s or of a protected
container, the folders models are kept in); anything that starts a model, a job, a service or another workload (a
container started, a model server, something left running, the GPU); anything that touches Spark Console’s own unit,
state, secrets or repository copy (only its installer changes those); anything about Spark 2’s power or its plug (its words anywhere, through `sh -c`, `busybox` or another program's text); root
and the lock-out class (later builds); and `minutes` (A6) is not on Spark 2 yet. Anything else is always asked, one
command a press (a command with a line break framed on the button, each line after │: `hubCommandLines`), whatever the words, a go-ahead or an agent say, and never run from the API. The press runs it inside the lock-out net
(`netGuarded`, R60, R71) through the owner’s service manager, outside the console’s own unit, with 2 GB. Spark Console’s own
ways in (the installer’s `check_ways`: the owner’s sign-in, the agent door, the model address; its route on Tailscale;
the brain) are tried before and after it with the net’s; one that stopped answering puts it back at once, pauses
Sparkie’s and agents’ changes and tells the owner; a put-back puts files back and starts no container (a stopped brain
is the owner’s `/restart sparkie`). Its wall hides `/run` (Docker’s socket, the service manager) and `/var/lib/docker`,
leaves Docker’s group out, and gives the model folders read-only (`--protect`), so a command the sorter can’t read still
can’t reach the brain; its button says so. A console restart leaves it to the net: at start `netRecover` finds the
guard by its id and puts it back, which stops the unit first, or the Spark’s own timer does; it never runs again.
Today: after a clean check it is kept by code; a fresh visit keeps it once A13c is built.
