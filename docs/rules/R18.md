# R18

## Rule

**R18.** A workflow runs only tested (the lock names this build and version). A tested but unvalidated version still
runs, as its validation run and with no question, for the owner’s `POST /actions`, a saved-workflow step, a clear
request to Sparkie, or healing. Its `code()` should list every function it runs. Today it does not (`memNow`,
`copyModel`, `inventory`, `claimSparks`, `runJob`, `pausedCheck` are missing; listed objects and Sets hash as
constants), so editing those forces a new lock but no new validation.

## Why

Unlisted code changes without a new validation.
