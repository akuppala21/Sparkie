# R29

## Rule

**R29.** `node test/lock.mjs` passes on the exact tree before installing; every action is in `TOOLS` or
`CHANGE_TOOLS`. The installer compares only the lock’s build id (`server.mjs`, `dig.mjs`, `passkey.mjs`), so a
`worker.py`-only edit installs with every workflow untested (off) and crash restarts off.

## Why

An unlocked build has every workflow off.
