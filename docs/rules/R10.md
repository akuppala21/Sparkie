# R10

## Rule

**R10.** Every command on a Spark goes through `spawnOn`; `run` never rejects, so test `code`. Today: ssh is spawned
only there; these local commands on Spark 2 skip it: tailscale ip, python3 for YAML, systemd-run (the rollback, and
`pull.sh install`), `pull.sh` (`setup`, `check`), tailscale status and serve status (four callers), tar for the backup,
and git, tar and node for Sparkie’s own code; HTTP to model servers does not use it.

## Why

Timeouts, offline memory and the test switch live there.
