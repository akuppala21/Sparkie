# Checking advice before returning it

This trial addresses two observed owner-facing errors. The first answer recommended deleting a destination directory based only on its name. Two later answers supplied shell fragments whose last command made a normal successful job exit with failure. The follow-up's primary fragment worked, but its optional alternative reintroduced the same defect.

The final trial keeps the research model, serving profile and native Hermes toolset fixed. It repairs the manual reader's handling of ordinary HTML lists. Its wording asks for one applicable recommendation, disposable test inputs for checking executable advice when feasible, the actual versions tested and evidence that a cleanup target is disposable. The reader repair and wording ship together in this experimental package. Only the reader's isolated source checks distinguish their effects.

Retest the two observed failures using the original questions and frozen criteria. Also test an independently selected new question, and record tool use on the ordinary arithmetic control. Give separate credit for a correct core recommendation and a fully supported answer. Run missing release checks on any candidate under consideration. A targeted repeat cannot establish transfer to other domains.
