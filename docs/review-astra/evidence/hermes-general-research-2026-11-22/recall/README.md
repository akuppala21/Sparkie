# Measurement and fresh-session recall

The owner asked Hermes to compare two prompt-cache settings on one local CPU endpoint and remember the result. The allocation served TinyStories with llama.cpp build 12464, one CPU thread, a 512-token context, one slot and zero GPU layers. It used the same model, exact prompt, greedy decoding and eight-token output cap for both settings. The frozen request required one warmup followed by three timed requests **for each setting**. Both experiments used fresh Hermes homes and private workspaces. [Measurement question](measurement.txt) · [First recall question](first-recall.txt)

The evaluator recomputed medians from successful HTTP requests, checked the submitted cache setting and token counters, compared generated text and counted the server's completed requests. The original skill ran six timed requests and one warmup. The cache-disabled setting had no warmup. Its collected medians were 2.124 and 2.370 milliseconds for cache disabled and enabled. The assistant saved a measurement note and a later session correctly recovered those numbers. It also repeated the incomplete procedure as if it met the owner's request. [Original timing counts and samples](original-timings.json)

For the correction check, the evaluator annotated the project summary with a dated disposition that identified the missing warmup. The seven responses, original measurement note and native memory stayed intact. The next fresh chat received a neutral question about the current result. It read the corrected summary and correctly reported the old timings as historical, the missing warmup and the need for a rerun. [Fresh question after correction](corrected-recall.txt)

An experimental change to the on-demand measurement skill asked Hermes to group requests by the actual setting and verify the phase and count for each group. That run made one exploratory schema request, followed by eight requests in the specified order. The independently verified medians were 2.134 and 1.247 milliseconds for the two settings. It timed out before a final owner reply or a saved native measurement note. The experimental skill was excluded from the candidate. [Trial timing samples and cache counters](trial-timings.json)

These observations describe the recorded TinyStories CPU runs. They provide no measurement of Huihui GPU throughput or of how much prompt caching will improve a different workload.
