## The same question with different evidence

The owner asked which of two print quotes to reserve. Cedar cost $864 for 240 prints. Birch cost $900 for 300. The short brief either specified the lowest qualifying invoice or left cost versus additional copies for the organizer to decide. Sparkie read the quotes and got the prices, difference and quantities right. In both chats it treated the suppliers' ready date as proof of delivery by the deadline. In the undecided case it recommended Birch before settling the tradeoff, then advised confirming the organizer's choice. No booking was made. ## A two-turn conversation in the browser

The owner asked which backup window to use. Either duration fitted. The longer option had no on-call coverage. The first answer recommended the covered window, then overstated what coverage guaranteed and what could happen without it. When the owner specified that extra time mattered more and requested one sentence, Sparkie correctly switched to the 50-minute option and gave the 28-minute difference. It added an unsupported assertion that duration was the job's risk.

Chromium submitted both messages in the same sealed Hermes Webapp conversation. Both final replies arrived on its native WebSocket and appeared at widths of 1280 and 390 pixels. Neither turn called a tool. The two observed times, including viewport capture, were 40.5 and 5.1 seconds. A subsequent read verified cleanup after an immediate poll returned a nonzero status. ## A repair checkout that silently selected zero tests

The published selector returned a clean plan for a changed extension nested under a different directory name. In a standalone Git checkout it exited with an error. The standard repository layout worked. The cause was the selector's hard-coded repository parent and `sparkie` path filter. Discovery now starts in the actual extension, resolves its Git worktree and scopes changes to the extension and shared contract files. The real CLI found both sides of a staged rename and an untracked skill in all three layouts. The changed-path command passed 46 checks on the distributable sources and 47 on the experimental tree. This repairs the test command Sparkie can use when working on itself. General repair quality remains a separate question.
