Nothing kept can lock the owner out, power or start anything by itself, download, notify unasked, or offer a way around a network that blocks ts.net.

## 4. Changes to the building blocks

- **No ninth block.** A plug is a field on a Spark's entry plus `power_on` and `power_off`; a release watch is a view over Way.
- **Way** serves a goal: a workload spec, a paste card or owner-run steps. Evidence is dated; "worked here" is written only by code.
- **Files:** `run_batch`'s worker is the one long runner (steps, ledger, checks, parking, stop and pick-up); research, test drives and background calls are kinds on it.
- **Procedure:** `checkSteps` now; later `folder`, `notes`, `put_away`. `notes` loaded on use is the owner's "skill"; no Skill block. The trigger is unbuilt and unattacked, so power-3, research-3, pipelines-5 and personal-1 wait; it is armed only by the owner, disarmed by any step change, with no stops and no downloads.
- **Conflict:** a long run may only be a last step, so "on for this job, off after" waits.
- **One more line in the block rule:** every action declares what undo can reverse, obeys the one pause, and adds hostile-text rows and an exposure row; containers start inside the fence.
- **Outside the blocks:** probes are fields on existing reads, never tools; agent keys gain a models-only scope, caps and an end date.

## A ninth block?

- **A switched device: no.** A plug is a field on a Spark: at most three entries, none added by saying so, and a Device block has no second kind of entry (other home devices belong to Home Assistant through Connector). Build `plug` (kind, LAN address) on each Spark's owner-written entry in access.json, one small part, two actions (`power_on`, `power_off`). Its password is a Secret.
- **A watch on outside releases: no.** Both attacked designs ended as asked-only reads with no timer or state (`whats_new`; `workloads {images:true}`), a dated view over Way's evidence. A standing one would be a Procedure trigger.

## Fewest changes

1. **Way:** "recipe for a workload" becomes "recipe for a goal": it yields a workload spec, a paste card, or owner-run steps. Evidence gains dated facts (date read, image digest, driver needed and ran on); worked-here is written only by code from a real run or call.
2. **Files:** `run_batch`'s worker becomes the one long runner: steps, ledger, code checks, parking while its model is off, stop and pick-up by name. Research, test drive, background calls and replay are kinds on it.
3. **Procedure:** fields `folder`, `notes`, run record, previous version; action `put_away`; trigger kind `idle`; `checkSteps` at save and before step 1. `notes` loaded on use is the owner's "skill": no Skill block. The trigger is unbuilt and unattacked; power-3, research-3, pipelines-5 and personal-1 wait on it.
4. **Conflict to settle:** the pipelines-1 attack allows a long run only as a last step; power-3's "on for this job, off after" puts `power_off` after `run_batch`. Until a step can wait on a long run, power-3 keeps only midnight and idle.
5. **Block rule, one added line:** before shipping, every block's actions declare an undo class, obey the one pause, and add hostile-text rows and an exposure row; any container starts inside the fence.
6. **Outside the blocks:** Spark record: `plug`; probes become fields in `fleet_status`, `spark_diagnostics` and `workloads`, never new tools, each with an inner timeout, exit 0, and skipped on a held Spark (verified: a timed-out probe marks the Spark unreachable, 02-ssh.mjs:60; a non-zero exit drops the watcher's round, 19-watcher.mjs:74). Key table (agents-4): scope models-only (`/v1` only), caps, defaults, end date.

- **Fits no block, defer:** practice-1 (`what_if`): unattacked; one missed early return is a real change behind a read.
- **Fit a block, drop anyway:** everywhere-5 (Door; a new internet-callable route to a model); webaddress-4 (no custom domain, owner's decision); research-5 (needs Workload's undesigned allowlist network).
- **Parked:** webaddress-2 (Door, Files, Secret): the workers.dev page awaits deletion; never an answer to a blocked network.
- **Plain hosted apps:** personal-4 (Immich, Paperless-ngx).
