# Source reader and comparison utility validation

This is a development update. It does not qualify a live release or unattended self-modification.

## Changes

GitHub project search retains short author descriptions from the same response. A README read additionally requests the repository's current fork, parent and source metadata. It preserves the requested repository, revision and exact file bytes. Missing or inconsistent metadata does not invalidate a verified README. Explicit file-path reads retain one GET. Current fork metadata cannot establish historical README age or authorship; nonfork status does not mean official. The extra request is anonymous and uses a 15-second socket timeout, not a total request deadline.

The developer evidence worksheet now keeps ratios within one recognized measurement record and supports complete quoted intervals. Unexplained numeric text withholds a comparison. The final regressions include grouped and scientific numbers, shared units, nonbreaking spaces, signed values and a denominator spanning zero. Unrelated numeric text may conservatively suppress a valid comparison. Literal checking cannot determine whether a claimed measurement was actually measured or whether the comparison is meaningful. This utility is not automatically invoked by owner chat.

## Focused checks

All execution below used compute Sparks, with no hosted AI or hosted CI. The final source-reader module passed 40 tests in 0.06 seconds. The final worksheet module passed 60 tests in 0.19 seconds. Both used offline, resource-limited containers. Earlier faulty worksheet variants and the failed compact setup were retained privately.

Five ordinary native Hermes research turns used the selected local Huihui model and unchanged generation settings. Two questions had baseline/candidate pairs, and one candidate-only control requested an exact fork commit. All five answered the requested facts with the required citations. Independent review of the complete answers passed two of five: three added unsupported claims about README age, the appropriate source for a particular fork, or a built-in pager.

Both Tailspin arms found the intended upstream immediately, so the previous fork-first mistake did not recur and recovery from it remains unproven. The bat origin candidate used 3 model requests in 55.894 seconds versus 7 in 145.303 seconds for the baseline. It named upstream before receiving metadata, so this demonstrates verification rather than discovery. Single samples do not establish a speed or accuracy improvement. The exact-fork candidate preserved its requested commit and citation.

The source change adds no agent loop, additional reviewer call, prompt change or model substitution. The native behavior evaluation is recorded separately below.

## Native behavior evaluation

The reader overlay on the sealed Unified6 baseline completed nine native cases in 293.06 seconds after 211.179 seconds of model startup. All 17 inference requests went to the isolated local selected model. Seven cases passed their automatic checks; independent whole-answer review passed six.

- Unknown preference: correctly kept an unknown IP null, but wrapped it in prose and Markdown instead of the required bare JSON, with an unnecessary skill lookup.
- Failed stop: read the complete receipt showing a failed stop and a still-running workload, but returned an unknown stopped field and attempted an unavailable tool. The operation still had one dispatch.
- Structured research: preserved both citations and the measured code/prose numbers without the earlier false doubling, but omitted that benchmark input and output lengths were unspecified.

The remaining cases covered simple response, confirmed memory addition/correction, corrected recall, same-ID reconciliation and untrusted source handling. Owner confirmations and memory used isolated fixtures; fleet dispatch was inert. The native compact is a regression screen, not proof of general research accuracy. The failed pre-inference setup used an obsolete container reference; it was retained and corrected before this fresh run. No failed model case was rerun to obtain a passing sample.

Three cleanup observations verified the model absent, its listener free, no GPU processes and no owned Hermes sandboxes. The compact/preflight containers and version-only sockets were separately verified absent. The live app and sealed release were unchanged. The release remains held because research completeness and reliable task reporting remain unresolved.
