KV cache dtype

Set --kv-cache-dtype fp8 to store the KV cache in 8 bits. It halves the cache's memory, so more requests fit.

  • fp8 works on Blackwell and Hopper.
  • auto keeps the model’s own type.
vllm serve my-model --kv-cache-dtype fp8

If you see ValueError: unsupported kv cache dtype, update vLLM.
